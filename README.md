# Sales Analysis with Python

Учебный проект автоматизации анализа продаж на Python.

## Возможности
- Загрузка данных из CSV
- Расчёт выручки по товарам
- Поиск лидеров продаж
- Сортировка по выручке и количеству
- Формирование Excel-отчёта

## Технологии
- Python
- Pandas
- OpenPyXL

# Запуск

1. Установить библиотеки:
   pip install pandas openpyxl

2. Открыть файл lesson3.ipynb в VS Code
   с расширениями Python и Jupyter.

3. Убедиться, что sale.csv находится
   в той же папке.

4. Выполнить все ячейки (Run All).

5. Получить файл sales_full_report.xlsx.

## Результат
Создаётся Excel-файл с четырьмя листами:
- Все продажи
- Лидеры
- Итоги
- Лидеры по количеству
